CivicX

Report. Track. Resolve.

CivicX is a simple civic issue reporting platform built to make local problems easier to report and easier for authorities to understand.

Citizens can report issues like garbage, broken roads, streetlights, and water leaks, add evidence, and track what happens next.

Authorities get a separate dashboard to manage reports, view trends, find hotspots, and prioritize problems.

Built with

Next.js • React • TypeScript • Firebase • Cloudinary • Leaflet • Recharts • Gemini AI
